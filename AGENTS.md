# Linux på GeekBox

## Formål

At få flashet GeekBox (RK3368) med en Linux distribution

## Status

GeekBox er flashet med Lubuntu V160309 (august 2026). Metode, værktøjer og kilder er dokumenteret i `README.md`.

Devuan Excalibur (armhf) booter fra SD med vendor-kernel 3.10: desktop (LXDE/fbdev), WiFi, HDMI-lyd, ssh (dropbear) — alt virker. Se `DOKUMENTATION.md` for den fulde historie, beslutninger og genskabelses-guide, og `TODO.md` for status/viderespor. Scripts i `devuan/`.
