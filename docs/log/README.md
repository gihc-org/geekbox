# Loggen

Daterede notater, ét pr. arbejdssession, ældste først. De er **append-only**:
de beskriver hvad der var sandt den dag, og rettes ikke bagefter.

Det betyder at stierne i dem kan være forældede. Et notat fra 26. august kan
sige "opdater `DOKUMENTATION.md` §5.15e" — den fil findes ikke længere, fordi
dokumentationen blev delt op i emnefiler 16. september. Oversættelsen fra de
gamle navne til de nye står i `../README.md`.

Skal du vide hvordan noget ser ud **nu**: læs `../README.md` og emnefilerne.
Skal du vide hvad der blev gjort og hvorfor: læs loggen.
